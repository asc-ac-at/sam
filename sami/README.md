sami: software and modules installer
====================================

Command line tool for building and installing software. Primarily used
to manage various types of installations required at the Austrian
Scientific Computing (ASC) Research Center, a high performance computing
center that focuses on providing heterogenous software installations to
users from various scientific fields.


## Under Development!

This software is under heavy development. If you need to install software, please use the existing
scripts in the `asc-software-layer-scripts` repository[^1].
