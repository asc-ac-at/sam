sami: software and modules installer
====================================

Command line tool for building and installing software. Primarily
used to trigger a software build and optionally publish it to a cvmfs
stratum0 server.

## Features

## Dependencies

`sami` is designed to work with `samctr`

## Installation

### build from source

The makefile in the root of the repository specifies a target. Simply
invoke `make` to produce the binary `build/sami`.
